# Knowledge

Một API key có thể nhìn thấy nhiều model và mỗi model có tập khả năng/giới hạn tham số khác nhau. RIS V3 lưu metadata capability để AI Wire dựng request phù hợp thay vì suy đoán từ tên model.

Các capability chuẩn: chat, streaming, temperature, vision, jsonMode, reasoning, toolCalling, embeddings.
